Declaración de Accesibilidad Web

La Universidad de Costa Rica (UCR) y las unidades responsables del programa (CIOdD, DIPROVID y Programa Auge) tienen el compromiso de facilitar la accesibilidad de la plataforma de la Caja de Herramientas de Inteligencia Artificial para la MiPYME para todas las personas participantes, incluyendo a aquellas con discapacidad o limitaciones de hardware y conectividad.

Nuestro objetivo de mejora continua es cumplir progresivamente con las pautas de accesibilidad para el contenido web (WCAG 2.2) nivel AA.

1. Medidas de Accesibilidad Implementadas

El sitio web estático implementa los siguientes estándares técnicos de accesibilidad:

  • Estructura Semántica Completa: Uso correcto de encabezados estructurados (`

  • Navegación por Teclado: Todas las secciones interactivas, menús laterales, botones de módulo y enlaces del sitio web pueden operarse mediante el teclado (usando la tecla `Tab` para avanzar, `Shift + Tab` para retroceder y `Enter`/`Space` para activar).
  • Foco Visible: Configuración de un indicador visual contrastante de foco en todo elemento interactivo activo para guiar a los usuarios que navegan por teclado.
  • Enlace de Salto (Skip-Link): Un enlace invisible en la cabecera que permite a usuarios con lectores de pantalla o navegación por teclado saltar directamente al contenido principal del sitio web.
  • Texto Alternativo Descriptivo: Las imágenes informativas y logotipos institucionales del sitio cuentan con descripciones de texto alternativo (`alt`). Las imágenes puramente decorativas implementan atributos vacíos para que sean ignoradas por lectores de pantalla.
  • Contraste Suficiente: El diseño visual utiliza colores institucionales de alta visibilidad asegurando un contraste adecuado entre el texto y el color de fondo.
  • Tablas Responsivas: Todas las tablas y rúbricas están envueltas en contenedores responsivos adaptados para pantallas pequeñas sin desborde, incluyendo leyendas explicativas (``).
  • Respeto al Rendimiento y Animaciones: Se implementa soporte para las preferencias del sistema operativo del usuario respecto a la reducción de movimiento (`prefers-reduced-motion`), inhabilitando transiciones o animaciones pesadas.

2. Reporte de Barreras de Accesibilidad y Retroalimentación

Si experimenta dificultades para acceder a alguna sección del sitio web o desea hacernos llegar sugerencias de mejora en materia de accesibilidad, le agradecemos ponerse en contacto con la coordinación académica del programa. Sus aportes nos ayudan a asegurar que este recurso educativo siga siendo abierto y verdaderamente inclusivo.
